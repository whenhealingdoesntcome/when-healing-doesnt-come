THE GOOD SCROLL - PHASE 1 (ADMIN EDITOR)

This patch adds a private Good Scroll editor and D1 table. It does not add a public feed, sharing, image export, or iOS navigation yet.

1. Copy the three src files from this ZIP into the matching paths in your WHDC website repository.
2. Copy GOOD-SCROLL-MIGRATION.sql to the repository root.
3. From the website repository root, run:
   npx wrangler d1 execute whdc-devotionals --remote --file=GOOD-SCROLL-MIGRATION.sql
4. Deploy the Worker normally:
   npx wrangler deploy
5. Sign into your admin dashboard and open:
   https://admin.whdcdevotions.com/admin/good-scroll
   (or use the Good Scroll link near the bottom of the admin dashboard).
6. Create a draft post and confirm it appears in the Post Library before publishing any posts.

IMPORTANT
- The database migration must run before the editor can save posts.
- Images use the existing AUDIO_BUCKET R2 binding, under the good-scroll/ prefix. No new bucket is needed.
- Published posts are stored but are not yet displayed in a public feed. Phase 2 will add the feed.
- Scripture references are required for published Scripture posts, but the wording must still be manually verified against WEBU before publishing.
- The editor is behind existing admin Cloudflare Access permissions.
- The PWA and iOS app files are not modified in this patch.
- This patch has been syntax-checked but not tested against the live D1/R2 environment.
